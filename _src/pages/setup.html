Before you drop the needle

Run it yourself

Groovy needs a Java runtime (JDK 17 or newer) and the Groovy command-line tools. Pick your system, then run any track with one command.

1 macOS or Linux

SDKMAN installs and switches Java and Groovy versions for you.

curl -s "https://get.sdkman.io" | bash
sdk install java
sdk install groovy
groovy --version

2 Windows

With Scoop (or choco install groovy with Chocolatey):

scoop bucket add java
scoop install temurin21-jdk groovy
groovy --version

3 Run a track

Download any example from its page, or clone the repository, then:

git clone https://github.com/SolutionsAsService/LearnGroovy
cd LearnGroovy/examples
groovy a2-closures.groovy

4 Play with it

groovyConsole opens a small editor where you can paste a track, change it and run it with Ctrl+R. groovysh is an interactive shell for one-liners.

Only track B4 needs the internet; the rest run offline.
