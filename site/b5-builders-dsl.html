A tiny DSL

Closures with a delegate let you write code that reads like configuration: here, a setlist.

b5-builders-dsl.groovy · 32 lines Download 
class Setlist {    String band    List<String> songs = []     void band(String name) { band = name }    void play(String song) { songs << song }    void encore(Closure more) {        play('--- encore ---')        more.delegate = this        more()    }     static Setlist build(@DelegatesTo(Setlist) Closure spec) {        def s = new Setlist()        spec.delegate = s        spec.resolveStrategy = Closure.DELEGATE_FIRST        spec()        s    }} def show = Setlist.build {    band 'The Grooves'    play 'Get Down'    play 'Far Out'    encore {        play 'Right On'    }} println show.bandshow.songs.eachWithIndex { song, i -> println "${i + 1}. $song" }

Expected output

The Grooves
1. Get Down
2. Far Out
3. --- encore ---
4. Right On

Written by hand from the code, not machine-run on this site. Run it yourself:
groovy b5-builders-dsl.groovy
