Null safety and truth

The safe-navigation operator ?., the Elvis operator ?: and Groovy truth: what counts as true.

a4-null-safety.groovy · 16 lines Download 
def fan = [name: 'Sam', address: null] println fan.address?.city            // null, not a NullPointerExceptionprintln fan.address?.city ?: 'unknown city' def nickname = ''println nickname ?: 'no nickname'    // empty string is false // Groovy truth[null, 0, '', [], [:], 'x', 1, [0]].each {    println "${it.inspect().padRight(6)} -> ${it as boolean}"} // Safe index on a possibly-null listList tracks = nullprintln tracks?.getAt(0)

Expected output

null
unknown city
no nickname
null   -> false
0      -> false
''     -> false
[]     -> false
[:]    -> false
'x'    -> true
1      -> true
[0]    -> true
null

Written by hand from the code, not machine-run on this site. Run it yourself:
groovy a4-null-safety.groovy
