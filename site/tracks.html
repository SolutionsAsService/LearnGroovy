Tracklist

12 tracks, two sides

Play them in order, or skip to the one you need. Each track is one runnable file, with the output it should print. Line counts are code only: the two header comments and the blank line after them are left out.

Side A The basics

  1. A1Hello, strings18 lines

    Strings, GStrings with ${} interpolation, multiline strings and a few handy String methods.

  2. A2Closures19 lines

    Blocks of code you can store, pass around and call: the it parameter, currying, and composition.

  3. A3Lists and maps18 lines

    Literal lists and maps, then the GDK methods that make them sing: collect, findAll, inject, groupBy, sort.

  4. A4Null safety and truth16 lines

    The safe-navigation operator ?., the Elvis operator ?: and Groovy truth: what counts as true.

  5. A5Ranges and switch22 lines

    Ranges as first-class values, and a switch that matches types, ranges, lists, regex and closures.

  6. A6Classes and traits30 lines

    Classes with automatic properties, named-argument constructors, @Canonical, and traits for mixing in behaviour.

Side B Real work

  1. B1JSON in and out22 lines

    Parse JSON with JsonSlurper, walk it like objects, and write it back out with JsonOutput.

  2. B2Files15 lines

    Write, read, append and walk files with the GDK's File methods, in a temporary folder so nothing on your disk changes.

  3. B3XML21 lines

    Build XML with MarkupBuilder, then read it back with XmlSlurper and GPath.

  4. B4HTTP and a REST API16 lines

    Call a real public API with nothing but the JDK, and read the JSON it returns. Needs an internet connection.

  5. B5A tiny DSL32 lines

    Closures with a delegate let you write code that reads like configuration: here, a setlist.

  6. B6Testing with assert13 lines

    Groovy's power assert prints every value in a failing expression, so a plain assert is a readable test.
