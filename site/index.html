Liner notes

Why Groovy?

Groovy runs on the Java virtual machine and reads Java code as-is, then lets you drop most of the ceremony: no semicolons, no getters and setters, list and map literals, closures everywhere, and a standard library that adds hundreds of handy methods to Java's classes.

You'll meet it in Jenkins pipelines, Gradle builds, Grails apps and the Spock test framework. If you know a little Java or JavaScript, Side A will feel familiar within minutes.
