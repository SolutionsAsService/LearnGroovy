Hello, strings

Strings, GStrings with ${} interpolation, multiline strings and a few handy String methods.

a1-hello.groovy · 18 lines Download 
def name = 'Groovy'def version = 4 println "Hello, ${name} ${version}!"println 'Single quotes are plain strings: ${not interpolated}' def poem = """\Roses are red,${name} is groovy,semicolons are optional"""print poem println name.toUpperCase()println name.reverse()println name * 3println "groovy".capitalize()println "a,b,c".tokenize(',')

Expected output

Hello, Groovy 4!
Single quotes are plain strings: ${not interpolated}
Roses are red,
Groovy is groovy,
semicolons are optional
GROOVY
yvoorG
GroovyGroovyGroovy
Groovy
[a, b, c]

Written by hand from the code, not machine-run on this site. Run it yourself:
groovy a1-hello.groovy
