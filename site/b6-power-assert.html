Testing with assert

Groovy's power assert prints every value in a failing expression, so a plain assert is a readable test.

b6-power-assert.groovy · 13 lines Download 
def bpm(String song) {    [ 'Get Down': 112, 'Far Out': 96, 'Right On': 124 ][song]} assert bpm('Get Down') == 112assert bpm('Far Out') < 100println 'all good so far' try {    assert bpm('Right On') + 1 == 124} catch (AssertionError e) {    println e.message}

Expected output

all good so far
assert bpm('Right On') + 1 == 124
       |               |   |
       124             125 false

Written by hand from the code, not machine-run on this site. Run it yourself:
groovy b6-power-assert.groovy
