JSON in and out

Parse JSON with JsonSlurper, walk it like objects, and write it back out with JsonOutput.

b1-json.groovy · 22 lines Download 
import groovy.json.JsonOutputimport groovy.json.JsonSlurper def text = """{  "band": "The Grooves",  "members": [    {"name": "Ana",   "plays": "bass"},    {"name": "Bilal", "plays": "drums"},    {"name": "Chen",  "plays": "keys"}  ]}""" def json = new JsonSlurper().parseText(text)println json.bandjson.members.each { println "${it.name} plays ${it.plays}" }println json.members.find { it.plays == 'drums' }.name def setlist = [band: json.band, songs: ['Get Down', 'Far Out'], encore: true]println JsonOutput.toJson(setlist)println JsonOutput.prettyPrint(JsonOutput.toJson([ok: true]))

Expected output

The Grooves
Ana plays bass
Bilal plays drums
Chen plays keys
Bilal
{"band":"The Grooves","songs":["Get Down","Far Out"],"encore":true}
{
    "ok": true
}

Written by hand from the code, not machine-run on this site. Run it yourself:
groovy b1-json.groovy
